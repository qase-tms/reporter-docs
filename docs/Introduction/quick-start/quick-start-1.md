If you’re new to automation or just want to test out the integration quickly, we’ve put together a few example repositories you can clone. These projects show how the Qase reporters work in different frameworks and provide a basic setup you can use or build on.

These examples show you:

* How to set up the Qase reporter for each framework
* How test results are reported
* What the syntax and config look like

Here are the available examples, grouped by language:
