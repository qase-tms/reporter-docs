If you’re new to automation or just want to test out the integration quickly, we’ve put together a few example repositories you can clone. These projects show how the Qase reporters work in different frameworks and provide a basic setup you can use or build on.

These examples show you:

- How to set up the Qase reporter for each framework
- How test results are reported
- What the syntax and config look like

Here are the available examples, grouped by language:

| Javascript                                                | Python                                                   | Java                                                                  | C#                                              | PHP                                                         |
| :-------------------------------------------------------- | :------------------------------------------------------- | :-------------------------------------------------------------------- | :---------------------------------------------- | :---------------------------------------------------------- |
| [Playwright](https://github.com/qase-tms/qase-playwright) | [Pytest](https://github.com/qase-tms/qase-pytest)        | [TestNG](https://github.com/qase-tms/qase-testng)                     | [xUnit](https://github.com/qase-tms/xunit-demo) | [phpunit](https://github.com/qase-tms/phpunit-demo)         |
| [Cypress](https://github.com/qase-tms/qase-cypress)       | [Robotframework](https://github.com/qase-tms/qase-robot) | [Junit5](https://github.com/qase-tms/qase-junit)                      |                                                 | [codeception](https://github.com/qase-tms/codeception-demo) |
| [Jest](https://github.com/qase-tms/qase-jest)             | [Behave](https://github.com/qase-tms/qase-behave)        | [Junit4](https://github.com/qase-tms/qase-junit/tree/junit4)          |                                                 |                                                             |
